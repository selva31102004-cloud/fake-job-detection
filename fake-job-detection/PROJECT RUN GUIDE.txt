A2 — CREATE A PYTHON VIRTUAL ENVIRONMENT
─────────────────────────────────────────────────────────────

What is a virtual environment?
  → It creates an isolated Python space just for this project.
  → Packages installed here won't affect other Python projects.
  → Think of it like a separate room just for FraudShield.

Navigate into backend folder first:
  cd backend

Create the virtual environment:
  python -m venv venv

  This creates a folder called "venv" inside backend/.
  It contains a clean Python copy + pip for this project only.

Activate the virtual environment:

  Windows CMD:
    venv\Scripts\activate.bat

  Windows PowerShell:
    venv\Scripts\Activate.ps1

  Mac / Linux:
    source venv/bin/activate

After activation, your prompt changes to show (venv):
  Example: (venv) C:\...\backend>
  This means the virtual environment is active. ✅

A4 — SET UP MYSQL DATABASE
─────────────────────────────────────────────────────────────

The backend uses MySQL to store user accounts (login/register).
You must create the database before starting the server.

Step 1: Open MySQL in a NEW command prompt window (keep venv window open):
  mysql -u root -p

  → Enter your MySQL root password when prompted.
  → You will see: mysql>

Step 2: Run the setup script:
  source db_setup.sql;
  OR copy-paste this manually:

    CREATE DATABASE IF NOT EXISTS login_system
      CHARACTER SET utf8mb4
      COLLATE utf8mb4_unicode_ci;
    USE login_system;
    CREATE TABLE IF NOT EXISTS users (
        id            INT AUTO_INCREMENT PRIMARY KEY,
        first_name    VARCHAR(100)         NOT NULL,
        last_name     VARCHAR(100)         NOT NULL,
        email         VARCHAR(255) UNIQUE  NOT NULL,
        password_hash VARCHAR(128)         NOT NULL,
        salt          VARCHAR(64)          NOT NULL,
        is_active     TINYINT(1)           NOT NULL DEFAULT 1,
        last_login    DATETIME             NULL,
        created_at    DATETIME             NOT NULL DEFAULT CURRENT_TIMESTAMP,
        updated_at    DATETIME             NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
        INDEX idx_email (email)
    ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

Step 3: Verify tables were created:
  SHOW TABLES;

  Expected output:
  +------------------------+
  | Tables_in_login_system |
  +------------------------+
  | users                  |
  +------------------------+

Step 4: Exit MySQL:
  exit;

METHOD B — DOCKER SETUP (Recommended — Easiest)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

What is Docker?
  → Docker packages the entire app (Python, packages, Tesseract, Nginx)
    into isolated "containers". You don't install anything manually.
  → One command starts the whole stack.

─────────────────────────────────────────────────────────────
B1 — INSTALL DOCKER
─────────────────────────────────────────────────────────────

Windows / macOS:
  Download Docker Desktop: https://www.docker.com/products/docker-desktop/
  Install and launch Docker Desktop.
  Wait until Docker Desktop shows "Engine running" in the taskbar.

Linux (Ubuntu):
  sudo apt-get update
  sudo apt-get install docker.io docker-compose
  sudo systemctl start docker
  sudo systemctl enable docker

Verify Docker is installed:
  docker --version
  docker-compose --version

Expected output:
  Docker version 24.x.x
  Docker Compose version v2.x.x

─────────────────────────────────────────────────────────────
B2 — IMPORTANT: ADD MYSQL TO DOCKER COMPOSE
─────────────────────────────────────────────────────────────

The default docker-compose.yml does NOT include a MySQL container.
You need to add it so the backend can connect to a database.

Open: fake-job-clean/fake-job-detection/docker-compose.yml
Replace its entire contents with this updated version:

────────────────── docker-compose.yml ──────────────────────
version: '3.8'

services:
  db:
    image: mysql:8.0
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: Selv@R@1
      MYSQL_DATABASE: login_system
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
      - ./backend/db_setup.sql:/docker-entrypoint-initdb.d/db_setup.sql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 5

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    ports:
      - "8000:8000"
    volumes:
      - ./backend:/app
    environment:
      - PYTHONUNBUFFERED=1
      - DB_HOST=db
      - DB_PORT=3306
      - DB_NAME=login_system
      - DB_USER=root
      - DB_PASSWORD=Selv@R@1
    depends_on:
      db:
        condition: service_healthy
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 10s
      retries: 3

  frontend:
    image: nginx:alpine
    ports:
      - "3000:80"
    volumes:
      - ./frontend:/usr/share/nginx/html:ro
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      - backend
    restart: unless-stopped

volumes:
  mysql_data:
─────────────────────────────────────────────────────────────

Save the file after editing.

B4 — BUILD AND START ALL CONTAINERS
─────────────────────────────────────────────────────────────

Run this single command:

  docker-compose up --build

What this does step by step:
  → Pulls MySQL 8.0 image from Docker Hub
  → Pulls Python 3.11-slim image from Docker Hub
  → Pulls Nginx Alpine image from Docker Hub
  → Installs Tesseract OCR inside the backend container
  → Installs all Python packages from requirements.txt
  → Runs db_setup.sql to create the login_system database + users table
  → Starts the FastAPI backend on port 8000
  → Starts Nginx frontend on port 3000

First build takes 3–7 minutes (downloading images and packages).
Subsequent starts are fast (under 30 seconds).

Wait until you see these lines:
  fake-job-detection-db-1        | ready for connections
  fake-job-detection-backend-1   | Application startup complete.
  fake-job-detection-frontend-1  | start worker process

  docker-compose logs -f

TROUBLESHOOTING — COMMON ERRORS & FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ERROR: "python is not recognized as a command"
  → Python is not added to PATH.
  → Reinstall Python and check "Add Python to PATH" during setup.
  → Or use: py --version (Windows alternative)

ERROR: "pip is not recognized"
  → Run: python -m pip install -r requirements.txt

ERROR: "tesseract is not installed or not in your PATH"
  → Install Tesseract OCR (see Step 0, Pre-Requirements ③)
  → Windows: make sure C:\Program Files\Tesseract-OCR\ is in PATH

ERROR: "Access denied for user 'root'@'localhost'"
  → Wrong MySQL password in .env file or auth.py
  → Default password in auth.py is: Selv@R@1
  → Change it in .env: DB_PASSWORD=your_actual_password

ERROR: "Can't connect to MySQL server on 'localhost'"
  → MySQL is not running.
  → Windows: Open Services → find "MySQL80" → Start it
  → Linux:   sudo systemctl start mysql
  → macOS:   brew services start mysql

ERROR: "Port 8000 is already in use"
  → Another process is using port 8000.
  → Windows: netstat -ano | findstr :8000 → taskkill /PID <PID> /F
  → Linux:   sudo kill -9 $(lsof -t -i:8000)

ERROR: "Port 3000 is already in use"
  → Change port: python -m http.server 3001
  → Then open http://localhost:3001

ERROR: Docker — "Cannot connect to the Docker daemon"
  → Docker Desktop is not running.
  → Open Docker Desktop and wait for "Engine running".

ERROR: Docker — "db_setup.sql: Permission denied"
  → Give the SQL file read permission:
  → Linux/Mac: chmod 644 backend/db_setup.sql

ERROR: "ModuleNotFoundError: No module named 'fastapi'"
  → Virtual environment is not activated.
  → Run: venv\Scripts\activate.bat (Windows) or source venv/bin/activate (Mac/Linux)
  → Then retry: pip install -r requirements.txt

ERROR: "mysql.connector.errors.DatabaseError: 1049 Unknown database 'login_system'"
  → Database not created. Run db_setup.sql in MySQL first (see Step A4).
